\# SensiCare



O SensiCare é um app para ajudar pessoas sensíveis a se locomover pela cidade com ajuda do Mapa Calmo.



Por enquanto, o projeto tem quatro telas feitas com React: Menu, Início, Login e Cadastro.



\## Como rodar



1\. Instale as dependências: `npm install`

2\. Inicie o site: `npm run dev`

3\. Abra no navegador o endereço que aparecer no terminal.
